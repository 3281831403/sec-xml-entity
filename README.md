把用户输入拼进配置模板时只转义了尖括号，一个与号就把整份配置解析废了：文本转义只处理小于号和大于号，五个预定义实体中的与号没有转义；属性转义不处理双引号，双引号属性值提前结束；属性转义不处理单引号，单引号属性值被截断；反转义只接受十进制数字引用，十六进制引用原样保留；反转义不校验引用码点，零值等控制字符进入结果；码点校验把代理区当作合法，孤立代理项可以通过；实体归一不统一进制，同一字符的十进制与十六进制写法并存；只转义一次的函数不识别已有实体，二次转义把与号变成双实体；往返一致判定只比较长度，内容不一致也算通过；批量转义复用转义表，第二条沿用第一条的引号类型。xmlesc/escape.py 是核心，tests/test_escape.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

测试组成
========

tests/test_escape.py 恰好包含 15 个测试。前 10 个测试名以 test_defect_ 开头，按题面顺序逐条对应 10 个缺陷；另外 5 个测试覆盖五个预定义字符全部变化、转义再反转义得到原文、十六进制引用可反转义、非法码点被拒、两批独立转义与单独转义相同。

十条边角约定
============

1. 文本转义处理五个预定义实体：与号写成 &amp;，小于号写成 &lt;，大于号写成 &gt;，双引号写成 &quot;，单引号写成 &apos;。与号必须先处理，原始文本中的与号不得原样留下。
2. 属性转义始终处理与号、小于号和大于号；quote 为双引号时额外把双引号写成 &quot;，quote 为单引号时额外把单引号写成 &apos;，另一种引号原样保留。quote 只接受一个双引号字符或一个单引号字符，其他值抛 ValueError。
3. 单引号属性必须使用单引号上下文：单引号写成 &apos;，不能因为只处理双引号而让单引号属性被提前截断。单引号上下文不额外改写双引号。
4. 反转义支持五个命名实体、十进制数字字符引用、以 x 或 X 标记的十六进制数字字符引用。十六进制引用必须解码，不能原样保留；反转义只做一遍，不递归解码结果。
5. 反转义必须校验每个数字引用指向的码点。U+0000 到 U+0008、U+000B、U+000C、U+000E 到 U+001F 等控制字符以及非法码点一律抛 ValueError，不能把控制字符带进结果。未知实体、裸与号和畸形引用同样抛 ValueError。
6. 码点合法性按 XML 1.0 判断：U+0009、U+000A、U+000D、U+0020 到 U+D7FF、U+E000 到 U+FFFD、U+10000 到 U+10FFFF 合法。U+D800 到 U+DFFF 的代理区、U+FFFE、U+FFFF、负数与大于 U+10FFFF 的值全部非法，valid_codepoint 必须返回真正的布尔值。
7. 实体归一逐个扫描数字字符引用，把十进制和十六进制写法统一成无前导零的十进制形式，使同一字符只有一种数字写法；命名实体和普通文本不改写，非法数字引用抛 ValueError。
8. 只转义一次的函数保留已经合法的命名实体和数字字符引用的原有拼写，只转义其余与号以及小于号、大于号、双引号、单引号。函数必须幂等，不能把 &amp; 变成 &amp;amp;。
9. 往返判定必须逐字符比较转义再反转义的结果与原文，并先确认原文每个码点合法。两者内容和长度都一致才返回 True；只比较长度、忽略非法控制字符或把内容不一致判为通过都算失败。
10. 批量转义接收两个同键映射：texts 的值是原文，policy 的值为 text、attr_double、attr_single 之一，返回同键映射。每个键独立选择转义上下文，第二条不得沿用第一条的引号类型，批量结果必须与逐条单独调用完全一致。
